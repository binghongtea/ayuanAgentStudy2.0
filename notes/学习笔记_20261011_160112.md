# 学习笔记：Python 列表的 `append()` 与 `pop()`

## 一、主题概览

Python 列表可以修改。这里重点学习两个常用操作：用 `append(x)` 添加元素，以及用 `pop()` 删除并取得元素。

## 二、核心知识点

- `append(x)`：把元素 `x` 添加到列表末尾，并修改原列表。
- `pop()`：默认删除列表最后一个元素，同时返回被删除的元素。

### 原文示例

```python
numbers = [1, 2]
numbers.append(3)
value = numbers.pop()
```

变化过程：

1. 初始时，`numbers` 是 `[1, 2]`。
2. 执行 `numbers.append(3)` 后，`numbers` 变为 `[1, 2, 3]`。
3. 执行 `value = numbers.pop()` 后，最后一个元素 `3` 被删除并赋给 `value`。
4. 最终，`value` 为 `3`，`numbers` 恢复为 `[1, 2]`。

## 三、知识关系与易错点

- `append()` 负责在末尾添加元素，`pop()` 默认从末尾取出并删除元素。
- 容易误解：`pop()` 只是查看最后一个元素。准确解释：它会同时删除并返回该元素。
- 要区分两个结果：`pop()` 的返回值保存在 `value` 中，而原列表 `numbers` 也发生了变化。

## 四、快速复习

- 列表是可修改的。
- `append(x)`：末尾添加 `x`。
- `pop()`：删除并返回最后一个元素。

## 五、自测题

1. “Python 列表可以修改”是什么意思？
2. 执行下面的代码后，`item` 和 `data` 分别是什么？

   ```python
   data = [5, 6]
   data.append(7)
   item = data.pop()
   ```

3. 已知 `names = ["小林"]`，要在列表末尾添加 `"小王"`，应写哪条语句？

## 六、参考答案

1. 列表创建后，其内容仍可以通过添加或删除等操作发生变化。
2. `item` 是 `7`，`data` 是 `[5, 6]`。因为 `append(7)` 先添加 `7`，随后 `pop()` 删除并返回它。
3. `names.append("小王")`。
