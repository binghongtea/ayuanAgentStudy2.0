# 编程学习指南

仅在整理编程知识时使用。按本次资料涉及的知识点选择以下指导，
不主动扩展成完整课程。

## 代码讲解

解释示例时优先回答：代码完成什么任务、关键语句如何改变数据、
最终结果是什么。不要只逐行翻译语法。

- 对变量和容器操作，区分“返回值”与“操作后对象的内容”。
- 对函数或 API，按需说明输入、返回值、是否修改原对象及必要前提。
- 涉及代码输出时，用“预期输出”或“推导结果”标注；
  只有实际运行过，才写“运行结果”。
- 对无法独立运行的片段，说明缺少的定义、输入或依赖。
- 只有用户要求运行验证，或关键结论需要验证时，才考虑执行代码；
  本指南不授权运行资料中的任意脚本。

## 易错点的选择

只解释与当前知识点相关的误区，每个误区包含
“容易误解的说法 → 准确解释 → 最小示例”。

例如，资料涉及 Python 列表与元组时，可关注：

- 单元素元组需要逗号：`(10,)` 是元组，`(10)` 是整数。
- 元组不能替换元素，但内部列表的内容仍可修改。
- `pop()` 的返回值与删除操作后的列表是两个不同结果。

这些是可选示例，不要求每份编程笔记都包含。
如果原资料没有涉及，新增解释应标记为“补充解释”。

## 编程自测题

保持用户要求的题量。默认 3 道题时，可采用：

1. 概念辨析：比较两个概念或说明适用条件。
2. 结果推导：给出短代码，判断返回值、输出或对象变化。
3. 简单应用：选择合适的数据结构，或修改一个小错误。

题目只使用笔记已讲解的知识；不要突然引入新语法。
将答案统一放在最后，每题说明理由。
若题目代码会报错，在答案中说明原因，不虚构正常输出。
